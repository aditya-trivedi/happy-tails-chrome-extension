# Hello Puppy

Chrome extension that adds a cute clip-art puppy to the bottom of every webpage.

## Install (Chrome)

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder
5. Visit any http(s) website — Hello Puppy appears at the bottom

## Behavior
- Clip-art puppy with ear twitches and eyes that follow the cursor
- Roams along the bottom (slow / normal / excited), staying away from the corners
- Idle: blink, ear twitch, look around, stretch/yawn
- Tail wags calm or excited

## Controls
- **Click** — give paw
- **Double-click** — roll
- **Shift+click** — biscuit treat + chew
