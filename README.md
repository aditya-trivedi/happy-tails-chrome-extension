# Pawsome

Chrome extension that adds a little dog or cat companion to the bottom of every webpage.

See [BRAND.md](BRAND.md) for colors, type, logo, and voice.

## Install (Chrome)

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder
5. Visit any http(s) website — a Pawsome companion appears at the bottom

## Behavior

- Clip-art dog or cat, chosen at random per page
- Ear twitches and eyes that follow the cursor
- Roams along the bottom (slow / normal / excited), staying away from the corners
- Idle: blink, ear twitch, look around, stretch/yawn
- Tail wags (dog) or swishes (cat)

## Controls

- **Click** — paw five
- **Double-click** — roll
- **Shift+click** — treat + chew

Store listing copy and promo images are in `store-listing.md` and `store-assets/`. Rebuild icons and promo art with `brand/build_assets.py`.
